# CommunityPeople coverage fixture

This page exists only in the end-to-end coverage build. `CommunityPeople`
resolves its roster with `peopleData.people[section] || []`
(`src/components/CommunityPeople/index.js` line 134), and the published pages
render only `section="tab"` and `section="staff"` — both of which
`data/community-people.json` always defines, because
`tests/community-people-data.test.mjs` fails the build if a section rendered
under `docs/` is missing or empty. The `|| []` arm is therefore unreachable from
published content, and a data overlay cannot reach it either: emptying a section
would give `[]` from the object rather than from the fallback.

The section below is named so that no refresh of `data/community-people.json`
can ever define it.
