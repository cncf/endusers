# EventsCatalog coverage fixture

This page exists only in the end-to-end coverage build. `/events` renders
`EventsIndex`, which hands the events-catalog plugin's years to
`EventsCatalog`. The published pages under `docs/events/<year>/` are all
multi-day events within one calendar month, and there is always at least one,
so three arms of the component and of `formatDateRange()` in
`src/components/shared/formatDate.js` are unreachable from published content:
the empty state, the start-day-only calendar block for a single-day or
month-spanning event, and the range text for an event that crosses a month or
a year. A data overlay cannot reach them either; the catalog is read from
Markdown front matter, not from a `data/*.json` file.

The first render below is the empty catalog. The second holds one year with an
event for each of those date shapes, latest first. Each row links to a
published event page because the build rejects broken links; the fixture is
about the dates, not the destinations.
