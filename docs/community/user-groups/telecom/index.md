# Telecom User Group

The [CNCF Telecom User Group](https://github.com/cncf/telecom-user-group) is a community for telecom operators, vendors
and other organizations adopting and operating cloud native technologies. The group shares best practices, resources, use cases, and practical guidance for network functions, edge deployments, and carrier-grade platforms.

> **Status:** the group is under a renewal process and the co-chairs of the group are working on re-establishing the
  group meetings. 

## Who should join

- Network and platform engineers at telecom operators
- Architects designing cloud native network functions
- Engineering leaders modernizing telecom platforms with CNCF projects

## How to participate

- Visit the [GitHub repository](https://github.com/cncf/telecom-user-group) for meeting details, resources, and how to
  join
- Join `#ug-telecom` on [CNCF Slack](https://slack.cncf.io/)
- Introduce yourself and ask questions in the repository discussions
