User Groups are long-lived groups aligned to an industry vertical or problem
domain, that report directly to the
[Technical Advisory Board](/community/technical-advisory-board). See the
[User Group Governance](/community/technical-advisory-board/governance) page for
the full definition.

## Groups

- [Platform Engineering](/community/user-groups/platform-engineering) — cloud
  native collaboration for platform engineering end users.
- [Public Sector](/community/user-groups/public-sector) — cloud native
  collaboration for public-sector end users.
- [Telecom](/community/user-groups/telecom) — cloud native collaboration for
  telecom end users.
