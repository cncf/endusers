CNCF User Groups (UGs) are long-lived communities aligned with an industry
vertical, problem domain, or a common need of the CNCF End User community. They
report to the [Technical Advisory Board](../technical-advisory-board.md) and
follow the [User Group governance](../governance.md).

<DocCardList />

## Starting a new group

Community groups that have completed initiatives covering a gap in the current
User Group structure can propose becoming a UG. See the
[Formation](../governance.md#formation) section of the governance document for
the process, and reach out to the
[Technical Advisory Board](../technical-advisory-board.md) to get started.
