# Join CNCF as an End User

The CNCF End User Community is a vendor-neutral space where organizations that
run cloud native technologies in production come together to influence the
ecosystem, connect with peers, and accelerate their platform journeys. There are
two ways for an end user organization to join. Both grant access to the End
User Community; they differ in the benefits that come with them.

## Who qualifies as an end user

CNCF defines an end user as an organization that uses cloud native technologies
internally to build, deploy, and operate its own software, systems, or
services. The definition excludes:

- Companies that commercially distribute, support, or sell software generated
  by CNCF projects.
- Companies that sell or commercially distribute other products or services
  that enable, host, optimize, monitor, or secure cloud native technologies.
- Training providers that sell courses, training services, educational content,
  or professional certification related to cloud native technologies.
- Consultancies and systems integrators.

Selling or distributing plug-ins that integrate with CNCF project software, or
contributing such plug-ins upstream, does not disqualify an organization. CNCF
may approve exceptions case by case, including for organizations that meet the
definition apart from a small portion of their business. The authoritative text
is the
[End User Definition](https://www.cncf.io/enduser/#end-user-definition) on
cncf.io.

## Option 1: End User Contributor

The
[End User Contributor Program](https://www.cncf.io/end-user-contributor-application/)
is a zero-fee pathway into the community. End User Contributors receive:

- Access to End User-only events, programs, and discussion forums, including
  the private End User mailing list and `#enduser` Slack channel.
- Eligibility to run for and serve on the
  [End User Technical Advisory Board](../technical-advisory-board/index.md).
- Recognition as a CNCF End User Contributor, including a listing in the
  [End User Directory](/community/members).

This is the right starting point for an organization that wants to take part in
the community before, or instead of, committing to a paid membership.

## Option 2: CNCF member

Organizations that meet the end user definition can also join CNCF as paying
members. Members receive everything End User Contributors receive, plus
membership benefits such as:

- KubeCon + CloudNativeCon in-person tickets.
- Linux Foundation training and certification coupons.
- An End User Recruiting Booth at KubeCon + CloudNativeCon at discounted
  pricing.
- Display of the organization's logo on the CNCF website and the
  [interactive landscape](https://landscape.cncf.io/), and use of the CNCF
  member logos.
- Announcement in the quarterly CNCF new-member press release.

Benefits grow with the membership level. Higher levels add Governing Board
participation, thought-leadership programs on CNCF channels, press and keynote
recognition, and more, and Platinum end user members may appoint a
representative to the End User Technical Advisory Board directly. The
[membership benefits comparison](https://www.cncf.io/about/join/#benefits) on
cncf.io lists the current levels, benefits, and pricing.

## Which path fits

| Consideration                      | End User Contributor | CNCF member          |
| ---------------------------------- | -------------------- | -------------------- |
| Fee                                | None                 | Annual dues by level |
| End User-only forums and events    | Yes                  | Yes                  |
| Run for the End User TAB           | Yes                  | Yes                  |
| KubeCon + CloudNativeCon tickets   | No                   | Yes                  |
| Training and certification coupons | No                   | Yes                  |
| Logo on cncf.io and the landscape  | No                   | Yes                  |
| Governing Board vote               | No                   | Silver and above     |

Either path puts your organization in the room with the maintainers, working
groups, and peer companies shaping the projects you depend on. Many
organizations begin as End User Contributors and move to membership as their
involvement grows; see the [contribution ladder](./index.md#contribution-ladder)
for how participation typically develops over time.
