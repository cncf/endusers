# Financial Services User Group

The
[CNCF Financial Services User Group](https://github.com/cncf/financial-user-group)
is a peer community for organizations using cloud native technologies in
financial services. Meetings focus on security, regulatory, compliance, and
operational practices specific to the industry.

## Who should join

- Practitioners and platform teams at banks, insurers, payment networks, and
  fintech firms
- Architects designing regulated, resilient cloud native systems
- Engineering leaders evaluating CNCF projects for financial services use cases

## How to participate

- Join the [mailing list](https://lists.cncf.io/g/financial-user-group/join) for
  meeting invites and announcements
- Join `#financial-user-group` on [CNCF Slack](https://slack.cncf.io/)
- Browse resources and past meetings in the
  [GitHub repository](https://github.com/cncf/financial-user-group)

## Meeting cadence

The group meets biweekly on Tuesdays at 11:00 AM US/Eastern. Check the
repository or mailing list for the next meeting and agenda.
