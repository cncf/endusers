# Resources Job Board Design

## Goal

Make the GitJobs job board easy to find from the CNCF End User Community's
Resources section.

## Design

Add a Job Board card to `docs/resources/index.md` that links directly to
`https://gitjobs.dev/` and opens in a new tab. Order the card after Radar
Reports and before Metrics so the landing-page grid mirrors the sidebar.

Keep the Resources sidebar's autogenerated entries so new pages continue to
appear automatically. Insert the Job Board link after Radar Reports and before
Metrics; it also opens in a new tab.

No intermediate page, data source, or generated content is needed.

## Validation

Run the repository's focused documentation validation for the changed Markdown
and JavaScript files, and verify the site build has no broken links.
