**November 10–13, 2025 · Atlanta, Georgia.**

The **End User Summit** brought together cloud native practitioners from
organizations using cloud native technologies in production. It was a forum for
sharing operational experience, architecture lessons, and practical guidance
with peers.

- [End User Summit — KubeCon + CloudNativeCon North America 2025 archive](https://events.linuxfoundation.org/archive/2025/kubecon-cloudnativecon-north-america/)

The **End User Reception** was a networking event for members of the CNCF End
User Community during KubeCon + CloudNativeCon.

- [KubeCon + CloudNativeCon North America 2025 event resources](https://events.linuxfoundation.org/archive/2025/kubecon-cloudnativecon-north-america/attend/event-resources/)
