The CNCF End User Community gathers at KubeCon + CloudNativeCon for focused events, conversations, and networking.

## Upcoming

### KubeCon + CloudNativeCon North America 2026

**November 9–12, 2026 · Salt Lake City, Utah.** The End User Summit and End
User Reception are historically part of the co-located/Day Zero schedule
(Monday, November 9); the Linux Foundation had not yet published dedicated
End User Summit or End User Reception pages as of this update, so the links
below point to the main event and schedule, which the Linux Foundation
keeps current as details are announced.

- [KubeCon + CloudNativeCon North America 2026](https://events.linuxfoundation.org/kubecon-cloudnativecon-north-america/)
- [Full schedule](https://events.linuxfoundation.org/kubecon-cloudnativecon-north-america/program/schedule/) — check back for End User Summit and End User Reception session details as they're published.

> This section is reviewed quarterly (or sooner once End User Summit/Reception
> details are published) so it never shows a past event as upcoming.
> Last verified: 2026-08-08.

## Past

### KubeCon + CloudNativeCon North America 2025

The **End User Summit** brought together cloud native practitioners from organizations using cloud native technologies in production. It was a forum for sharing operational experience, architecture lessons, and practical guidance with peers.

- [End User Summit — KubeCon + CloudNativeCon North America 2025 archive](https://events.linuxfoundation.org/archive/2025/kubecon-cloudnativecon-north-america/)

The **End User Reception** was a networking event for members of the CNCF End User Community during KubeCon + CloudNativeCon.

- [KubeCon + CloudNativeCon North America 2025 event resources](https://events.linuxfoundation.org/archive/2025/kubecon-cloudnativecon-north-america/attend/event-resources/)

> Event pages and schedules are maintained by the Linux Foundation.
