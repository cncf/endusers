# Case Studies

Real-world stories of CNCF end users running cloud native technologies in
production. Filter by CNCF project, industry, or country, or search by
organization name, then follow the link to read the full case study on cncf.io.

import CaseStudies from '@site/src/components/CaseStudies';

<CaseStudies />

This table mirrors [cncf.io/case-studies](https://www.cncf.io/case-studies/) and
is regenerated by running
[`scripts/collect-case-studies.mjs`](https://github.com/cncf/endusers/blob/main/scripts/collect-case-studies.mjs)
(`npm run collect:case-studies`); there is no scheduled workflow yet, so a
maintainer re-runs it manually to pick up new case studies. Each row's
description is hand-written and preserved across refreshes (cncf.io does not
publish one), so new case studies show a placeholder until a maintainer fills in
a real one-sentence summary. Case studies are authored and published by CNCF,
not by this project — to submit or correct one, see the
[CNCF case study program](https://www.cncf.io/case-studies/).
