# Survey Reports

CNCF survey reports include the CNCF Annual Survey, the State of Cloud Native
Development series produced with [SlashData](https://www.slashdata.co/), and
focused microsurveys on topics such as FinOps, GitOps, and training. Below is
every published survey report, newest first, with a brief description and a
link to the full report.

import SurveyReports from '@site/src/components/SurveyReports';

This list mirrors the Survey-type reports on
[cncf.io/reports](https://www.cncf.io/reports?_sft_lf-report-type=survey) and
is regenerated daily by
[`scripts/collect-survey-reports.mjs`](https://github.com/cncf/endusers/blob/main/scripts/collect-survey-reports.mjs)
via the `refresh-radar-reports` scheduled workflow, which opens a PR with any
new or changed reports.
