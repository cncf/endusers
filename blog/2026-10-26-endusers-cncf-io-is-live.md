The CNCF End User Community now has a single place to find what production
teams have learned from running cloud native technologies: reference
architectures, award winners, community groups, metrics, and the events where
end users meet.

The site is open source, and the people who use it are the ones who keep it
accurate. This post covers what is there today and how to take part.

{/*truncate*/}

## What you can find

- **[Reference architectures](/architectures/)** from end user organizations,
  reviewed through the [End User TAB's submission
  process](https://github.com/cncf/tab/blob/main/process/reference-architectures.md)
  and imported from the [CNCF architecture
  repository](https://github.com/cncf/architecture).
- **[Community](/community/)** pages for the [End User Technical Advisory Board
  (TAB)](https://github.com/cncf/tab), the user groups, and the channels where
  end users compare notes.
- **[End User Awards](/community/awards)**, a record of the organizations CNCF
  has recognized.
- **[Metrics](/metrics/)**, generated from public sources. Every figure links
  to its source, and a number we cannot source is left out.
- **[Events](/events/)**, including the End User Summit and End User Reception
  at KubeCon + CloudNativeCon.

## Who it is for

Practitioners, architects, and organizations running cloud native systems in
production. You do not need to be a CNCF member to read the architectures or
join the conversation.

## How to take part

- Join the `#enduser` channel in [CNCF Slack](https://slack.cncf.io/).
- Subscribe to the [End User mailing list](https://lists.cncf.io/g/cncf-enduser).
- Attend the [TAB public meeting](https://github.com/cncf/tab#meetings).
- Share your architecture through the [submission
  process](https://github.com/cncf/tab/blob/main/process/reference-architectures.md).
- Fix or improve a page by opening an issue or pull request in the [site
  repository](https://github.com/cncf/endusers); see its
  [contributing guide](https://github.com/cncf/endusers/blob/main/CONTRIBUTING.md).
- Learn about [joining the End User Community](https://www.cncf.io/enduser/).

If something here is out of date or wrong, tell us. That is the fastest way to
make the site more useful for the next team.
